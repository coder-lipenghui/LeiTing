导弹调整说明

用于调整雷霆战机项目中的导弹行为、发射模式、Prefab 视觉和拖尾效果。适合策划、美术、程序在 Unity 编辑器中协作使用。

一、先判断你要调什么

导弹飞行逻辑

调速度、追踪、锁定、爆炸、分裂、生命时间等，主要改 Luban/Datas/Missile.xlsx。

发射方式

调一次发几颗、角度、散射、是否瞄准玩家、连发等，主要改 Luban/Datas/MissilePattern.xlsx。

外观资源

调导弹图片、碰撞半径、Prefab 结构，主要看 Assets/Prefabs/Missiles/。

拖尾效果

调 Flame_Particle、Smoke_Particle、Spark_Particle、TrailRenderer，使用 Unity 菜单 LeiTing/Missiles/Visual Preview。

二、常用文件位置

文件或目录 用途 什么时候改
Luban/Datas/Missile.xlsx 导弹本体配置，控制行为类型、速度、生命、追踪、爆炸、尾焰颜色等。 要新增导弹，或调某种导弹自身手感时。
Luban/Datas/MissilePattern.xlsx 导弹发射模式，控制数量、角度、散射、连发、瞄准玩家等。 要改变敌机或 Boss 怎么发射导弹时。
Luban/Datas/WaveSpawn.xlsx 波次刷怪里可用 attackPatternId 覆盖敌机攻击模式。 只想让某一波敌人用某个导弹模式时。
Luban/Datas/BossPhasePattern.xlsx Boss 阶段里挂子弹或导弹模式。 要给 Boss 某个血量阶段加导弹攻击时。
Assets/Prefabs/Missiles/ 导弹 Prefab，包含碰撞体、主体图片、拖尾效果组件。 要调视觉、碰撞半径、拖尾挂点或特效参数时。
Assets/Art/Sprites/Bullets/ 导弹图片资源，例如 missile_01.png。 要替换导弹主体图时。

三、调整导弹本体

打开 Luban/Datas/Missile.xlsx 的 Missile sheet。每一行是一种导弹。

字段 说明 调整建议
id 导弹配置 ID，被 MissilePattern.missileId 引用。 新增时必须唯一，推荐类似 missile_weak_homing_1002。
behaviorType 导弹行为类型。 直线用 1，弱追踪用 3，锁定冲刺用 5，分裂用 8，爆炸用 9。
speed / maxSpeed / acceleration 基础速度、最大速度、加速度。 速度越高越难躲。追踪导弹建议先降低速度，再提高转向。
lifeTime 导弹存活时间。 太短会半路消失，太长会残留屏幕外；一般 4 到 8 秒。
damage / radius 伤害和碰撞半径。 大导弹半径可以略大，但不要超过图片视觉太多。
turnSpeed / trackTime / isLoopTrack 追踪转向速度、追踪时长、是否持续追踪。 弱追踪优先调 turnSpeed，强追踪再考虑 isLoopTrack。
lockDelay / warningTime 锁定冲刺前的等待和预警。 冲刺导弹必须给玩家反应时间，建议至少 0.3 秒。
explodeTime / explodeRadius 爆炸时间和爆炸范围。 范围越大越需要明显预警或较慢速度。
splitTime / splitCount / splitAngle / childMissileId 分裂时间、数量、角度、子导弹 ID。 先用 2 到 4 颗测试，再逐步增加密度。
prefabPath / bodyRes Prefab 路径和主体图路径。 Prefab 控制结构，bodyRes 控制运行时主体图片。
tailType / tailColor 尾焰类型和颜色。 常用 light、smoke、fire_smoke、spark、heavy。

行为类型速查

1 Straight 直线 2 Accelerate 加速 3 WeakHoming 弱追踪 4 StrongHoming 强追踪 5 LockAndDash 锁定冲刺 6 Curve 曲线 7 Wave 波形 8 Split 分裂 9 Explode 爆炸 10 Carrier 载体释放 11 Mine 地雷 12 Return 返回

四、调整导弹发射模式

打开 Luban/Datas/MissilePattern.xlsx。这里决定“怎么把导弹发出去”。

字段 说明 调整建议
id 发射模式 ID，被敌机、波次、Boss 阶段引用。 推荐带场景语义，例如 boss_missile_explode_03。
missileId 引用 Missile.id。 换导弹种类时改这里。
firePointGroup 发射挂点组。 必须和敌机或 Boss Prefab 的 FirePoints 子节点名称对应。
baseAngle 基础角度。 竖版向下通常用 180 或按现有配置复制。
missileCount / angleStep / spreadAngle 每轮数量、角度步进、总散射角。 扇形导弹先调 spreadAngle，再调数量。
missileSpeed / missileLifetime 覆盖导弹本体速度和生命周期。 填 0 或空值时使用 Missile 本体配置；只想某个模式变快时填这里。
aimAtPlayer 是否朝玩家方向发射。 追踪导弹不一定需要瞄准，直线导弹瞄准会更有压迫。
burstCount / fireInterval 连发轮数和间隔。 做 Boss 压制时常用，注意不要让屏幕密度过高。

五、编辑和预览拖尾效果

打开窗口

在 Unity 菜单选择 LeiTing/Missiles/Visual Preview。

选择 Prefab

把 Assets/Prefabs/Missiles/*.prefab 拖到 Missile Prefab，或在 Project 面板选中导弹 Prefab。

生成或刷新效果对象

点击 Add/Refresh Effect Objects On Prefab。Prefab 会补齐可编辑效果对象。

调整参数并看预览

在窗口里展开 Flame_Particle、Smoke_Particle、Spark_Particle、TrailRenderer，修改参数后预览会刷新。

效果块 主要控制 视觉结果
Flame_Particle 火焰粒子数量、寿命、速度、大小、颜色、排序层级。 决定尾焰核心亮度和喷射感。
Smoke_Particle 烟雾寿命、扩散大小、透明度、漂移、噪声、最大粒子数。 决定尾烟厚度、残留时间和柔和程度。
Spark_Particle 火星发射率、速度、散开角、大小、寿命。 用于重型导弹、Boss 导弹、可摧毁导弹的金属火星感。
TrailRenderer 拖尾持续时间、起止宽度、透明度、端点、材质、排序层级。 决定连续光带长度和粗细。
Tail Glow 尾部光晕开关、直径、透明度、脉冲速度。 让尾部更亮，不属于四个核心拖尾对象，但常一起调。
注意：不要手动删除 MissileVisualEffects 组件。需要重建效果对象时，优先使用预览窗口的刷新按钮。

六、推荐调参流程

  1. 先复制一个现有导弹配置和发射模式，确认能在游戏中发射。
  2. 只改 Missile.xlsx 的速度、生命、行为参数，跑一遍手感。
  3. 再改 MissilePattern.xlsx 的数量、角度、连发，确认屏幕密度。
  4. 最后打开 LeiTing/Missiles/Visual Preview 调拖尾效果。
  5. 配置表改完后运行 bash Luban/gen.sh 生成数据。
  6. 进 Unity 播放测试，看是否有导弹过快、预警不足、拖尾遮挡的问题。
小原则：先调玩法数值，再调视觉。视觉很好看但导弹太难躲，会让问题更难定位。

七、常见目标怎么调

目标 主要改哪里 建议
导弹更快 Missile.speed 或 MissilePattern.missileSpeed 如果只想某个敌人的模式更快，优先改 Pattern 的覆盖速度。
追踪更强 turnSpeed、trackTime、isLoopTrack 先增加 turnSpeed，再考虑延长追踪时间。
冲刺更有预警 lockDelay、warningTime、预警资源 冲刺速度越快，锁定等待越需要明显。
Boss 导弹更华丽 tailType、tailColor、Spark_Particle、Smoke_Particle 使用 fire_smoke 或 heavy，增加烟雾和火星，但注意不要遮住玩家。
减少屏幕压力 missileCount、burstCount、fireInterval、lifeTime 优先减少连发轮数或延长间隔，比单纯降低伤害更直观。
导弹更容易被打掉 canBeDestroyed、hp、radius 可摧毁导弹建议配更明显的烟雾或火星，玩家更容易识别。

八、检查清单

  • MissilePattern.missileId 是否能找到对应的 Missile.id。
  • prefabPath 是否指向存在的导弹 Prefab。
  • bodyRes 是否指向存在的导弹图片。
  • firePointGroup 是否和敌机或 Boss Prefab 上的 FirePoints 名称一致。
  • 修改 Luban 表后是否执行了 bash Luban/gen.sh。
  • 拖尾效果是否已经通过 LeiTing/Missiles/Visual Preview 预览过。
  • 烟雾和光带排序层级是否没有盖住玩家或关键预警。
如果游戏里没有变化：先确认改的是 Luban 源表，不是生成的 JSON；再确认已经重新生成并让 Unity 重新加载资源。
