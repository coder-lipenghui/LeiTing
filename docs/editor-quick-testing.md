# 编辑器关卡快速测试

## 打开入口

在 Unity 菜单中打开：

`LeiTing > Test > Level Selector`

窗口会读取当前 Luban 关卡、波次和关卡事件配置。绿色刻度表示普通敌机波次，蓝色刻度表示关卡事件，橙色刻度表示 Boss，Play Mode 中的白色刻度表示当前运行时间。

## 快捷指令

快捷指令格式为：

```text
关卡#时间
```

例如：

- `2#1:35`：第 2 关从 1 分 35 秒开始。
- `2#95`：第 2 关从第 95 秒开始，与上例等价。
- `2#0:00`：第 2 关从头开始。

输入后按回车或点击“开始”。Play Mode 中执行相同操作时，按钮显示为“重载”，会重新加载战斗场景。

## 时间轴操作

- 未运行时拖动时间轴，只修改下一次 Play 的测试起点。
- Play Mode 中拖动时间轴，松手后会从所选时间重新加载关卡。
- “上一个事件”和“下一个事件”会定位到相邻的波次或关卡事件。
- “提前 5 秒测试”会从下一个事件前 5 秒重载，适合观察 Boss 入场、提示和波次衔接。
- 时间文本框支持 `分:秒` 和纯秒数两种格式。

从非战斗场景点击“开始”时，工具会自动进入 `BattleScene`。测试关卡和时间会保存在 Unity Editor 偏好中，方便重复测试；从正常大厅开始关卡时，起始时间会重置为 `00:00`。

## 跳转语义

时间跳转采用“干净重载”，不会尝试保留当前场景中的敌机、子弹、掉落物、Boss 阶段或玩家战斗状态。

假设目标时间为 `T`：

- 开局计时器直接显示 `T`，准备阶段保持冻结，玩家第一次操作后继续计时。
- 起始时间严格早于 `T` 的波次和关卡事件会被标记为已跳过，不会集中补触发。
- 起始时间恰好等于 `T` 的波次和事件会正常触发。
- 玩家血量、分数、临时攻击强化和掉落记录从新战斗的初始状态开始，不模拟 `T` 之前的游玩结果。

因此，如果需要观察某个事件的完整过程，优先使用“提前 5 秒测试”，而不是从事件发生后的时间开始。
